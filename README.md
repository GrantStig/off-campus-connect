# Off Campus Connect

Course project repository for the CS 4604 final project.

## Repository Structure

- `backend/` server-side application code
- `frontend/` EJS templates and public assets
- `db/` schema and database setup scripts
- `docs/` diagrams, screenshots, and supporting materials
- `reports/` report drafts and final report assets
- `roles/` team member contribution summaries

## Run The App

1. Install dependencies with `npm install`
2. Add database credentials to `.env`
3. Start the server with `npm start`
